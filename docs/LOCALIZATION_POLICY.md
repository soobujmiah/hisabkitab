# Localization Policy

## Language-mode invariant

Songjog supports Bengali-first and English-first UI modes.

When Bengali mode is active, no English UI characters may be rendered by Songjog's own interface. When English mode is active, no Bengali UI characters may be rendered by Songjog's own interface.

This rule applies to navigation, buttons, labels, menus, dialogs, validation messages, empty states, onboarding, settings, receipts/templates generated by the application, and accessibility labels.

## User-provided content

User-entered names, addresses, notes, institution names, product names, and other business data are data rather than translated UI. The application must preserve such content exactly as entered and must not mutate it merely to satisfy UI language mode.

## Release requirement

Every supported UI surface must resolve text through the localization layer. Hard-coded UI strings are prohibited unless they are explicitly language-neutral symbols or identifiers that are not rendered as user-facing text.
